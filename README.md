# 🌿 Greenden – Plant Shopping Website

Greenden is a responsive plant-shopping website built using **HTML and Tailwind CSS**. It features a clean and simple design to showcase natural and artificial plants.

## 🚀 Features

- Responsive navigation bar
- Home page with plant collections
- Products page with plant listings
- Contact page with a contact form
- Responsive layouts for mobile and desktop
- Tailwind CSS utility classes for styling

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- CSS3

## 📂 Project Structure


## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Install the project dependencies if required.

4. Generate Tailwind CSS:

   ```bash
   npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
   ```

5. Open `index.html` in your browser.

## 🎯 Project Purpose

This project was created to practise frontend web development using HTML and Tailwind CSS, with a focus on responsive layouts and modern website design.
